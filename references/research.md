# 리서치

> 책쓰기 1단계. SKILL.md의 지시로 로드되는 실행 문서다. `BOOK`은 `python3 "$SKILL_DIR/scripts/book.py"`다.

너는 책의 사실 기반을 만드는 리서처다. 이 단계의 산출물은 이후 모든 단계가 인용할 수 있는 유일한 사실 창고다. 여기 없는 수치와 인용은 본문에 들어가지 않는다.

## 시작

1. `BOOK status`를 실행한다
   - `init`을 지시하면 `BOOK init`으로 새 책 폴더를 만든다
   - `01_research-notes.md`에 마커가 없다고 하면 **새 폴더를 만들지 않고** 그 파일에 이어 쓴다
2. 책 설정을 읽고 제목, 대상 독자, 목차, 저자 자료를 파악한다

## 조사 순서

### 1. 저자와 사내 자료 (Tier 0)

`user_input/sources/` 폴더(작업 폴더 기준)에 파일이 있으면 먼저 모두 읽는다. 책 설정 '저자 자료'의 실제 경험 메모도 여기에 속한다. 이 자료는 웹 자료보다 우선한다. '쓰면 안 되는 것'에 해당하는 내용은 노트에 옮기지 않는다.

### 2. 웹 조사 (Tier 1~3)

목차의 장마다 다음을 찾는다. 책 주제에 맞지 않는 항목은 건너뛴다.

- 정의와 기본 사실: 개념, 용어, 공식 명칭
- 최신 수치: 통계, 가격, 규모, 날짜 (공식 자료 우선)
- 실제 사례: 공개된 기업·기관·개인 사례
- 반론과 한계: 알려진 문제, 비판, 주의할 점
- 대안과 비교: 경쟁 개념, 다른 방법

## 출처 등급

SKILL.md '출처 신뢰도 등급'을 따른다. Tier 0과 Tier 1을 합쳐 60% 이상 확보한다. Tier 3은 '트렌드 시그널'로만 기록하고 사실 근거로 쓰지 않는다.

## 산출물

### `draft/{책}/01_research-notes.md`

- 목차의 부와 장 순서로 섹션을 나눈다
- 각 사실 옆에 출처 ID를 붙인다: `시장 규모는 3조 원이다 [[cite_007]]`
- 사실과 의견을 구분한다. 의견에는 `(의견)`을 붙인다
- 장마다 "본문에 쓸 수 있는 수치" 목록을 끝에 둔다. 집필 단계는 이 목록 밖의 수치를 쓰지 않는다

### `draft/{책}/01_citations.json`

```json
[
  {
    "id": "cite_001",
    "tier": 1,
    "title": "자료 제목 (기관, 발행 연월)",
    "url": "https://...",
    "claim": "이 출처가 뒷받침하는 사실 한 줄. 본문에 쓸 수치를 그대로 적는다 (예: 점유율 42%, 매출 3억 원)",
    "accessed": "2026-10-03"
  }
]
```

- Tier 0 자료는 `url` 대신 `"path": "user_input/sources/파일명"`을 쓴다
- ID는 `cite_001`부터 순서대로, 지우지 않고 늘리기만 한다 (본문 태그가 ID에 의존한다)
- 본문에서 실제로 쓰였는지는 `verify.py`가 `[[cite_…]]` 태그로 센다. 사람이 `used_in`을 관리하지 않는다
- `verify.py`는 본문 문장의 수치가 인용한 출처의 `claim`에 있는지 대조한다. 없으면 '출처 기록에 없는 수치'다 (수치 출처 필수가 '예'면 🟡, '엄격'이면 🔴). 단위까지 같아야 한다('63%' 기록으로 '63명'을 뒷받침할 수 없다). 그래서 `claim`에는 수치를 빠짐없이, 본문과 같은 숫자로 적는다

## 자료 추가 (리서치가 끝난 뒤)

사용자가 `user_input/sources/`에 자료를 더 넣었다고 하면, `01_research-notes.md`는 고치지 않는다 (고치면 그 뒤 단계가 모두 옛 자료 기준이 되어 되돌려야 한다). 대신 다음을 한다.

1. `draft/{책}/01_research-addendum.md`에 추가 자료의 요약과 "본문에 쓸 수 있는 수치"를 적는다
2. `01_citations.json` 끝에 새 ID를 이어 붙인다 (기존 ID는 바꾸지 않는다)
3. 다음 수정 단계에서 반영할 곳을 `_changelog.md`에 🟡 항목으로 남긴다 (출처: `01_research-addendum`)

## 완료

1. 노트 끝에 장별 자료 충분도를 표로 남긴다 (장, Tier 0~1 수, Tier 2 수, 부족한 점)
2. `BOOK complete 01_research-notes`
3. 사용자에게 한 줄로 알린다: `[4단계 중 1단계(리서치) 완료] 출처 N개 (공식 자료와 사내 자료 비율 X%). 다음: 목차 설계`
